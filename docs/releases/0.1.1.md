# DockMate-VS 0.1.1

Release date: 2026-09-10

## Highlights

- A dedicated Results tab beside Pose Viewer contains Summary and Charts,
  campaign-loading controls, and pose navigation.
- Screening dashboards provide ROC, precision-recall, docking-score
  distributions, and molecular-weight diagnostics, with figure export and
  score-range controls. Protocol-development panels are labelled A-D.
- Ligand preparation preserves supplied formal charges by default, with an
  explicit legacy neutralization option in GUI, headless, and Python workflows.
- Smart/adaptive ligand-variant selection has been removed. New runs default
  to docking all generated variants within the configured preparation limits.
- The external-tool installer isolates docking engines with conflicting native
  dependencies and supports user-downloaded LigPlot+ archives through
  `--ligplus-archive`, including validation, staged extraction, and dry runs.
- README and user-guide installation instructions are aligned. The Dockerfile
  fixes source-directory permissions during package installation.
- Python source distributions include the installation scripts, documentation,
  examples, and tests as well as the application code.

## Migration

- To resume otherwise-compatible campaigns created with legacy neutralization,
  select **Neutralize removable charges** or set `charge_handling: neutralize`.
  Changing charge policy requires a new campaign directory.
- Configurations containing `ligand_variant_mode: adaptive` are rejected.
  Reproduce those campaigns using their original software version, or select
  `all`, `best`, `first`, or `thorough` for a new campaign in a new directory.
- Docking all variants may take longer than the removed heuristic. Set explicit
  tautomer/conformer limits according to the intended campaign.
- Neither charge mode assigns or enumerates pH-dependent ionization states.
- Historical ESR1 results and manuscript figures are not regenerated by this
  release. Dashboard updates change presentation, not the saved docking scores.

## Distribution

The full source ZIP is the primary archive for installation following the README.
A Python source distribution and wheel are also provided. External docking tools,
conda environments, cached run outputs, and separately licensed LigPlot+ software
are not bundled. See `THIRD_PARTY_NOTICES.md` for third-party terms.

SHA-256 checksums and a release validation report accompany the release files.
The existing DOI `10.5281/zenodo.22283782` identifies version 0.1.0 and is not
assigned to this version. Update `CITATION.cff` with the new version DOI after
publishing 0.1.1 on Zenodo.
