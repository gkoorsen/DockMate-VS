# DockMate-VS 0.1.2

Release date: 2026-10-13

## Highlights

- View > UI scale offers persisted 100%, 125%, and 150% text and chart scaling.
  Tables, progress dialogs, and both chart implementations follow the setting;
  enlarged content remains scrollable and canvas charts redraw on resize.
- CSV/JSON results and restart checkpoints use null/empty missing RMSDs and
  `rmsd_status` (`ok`, `not_computable`, `not_applicable`). Applicable failures
  count against pose recovery, but never enter mean RMSD calculations.
- Open Babel conversion timeouts are configurable through preparation schemas,
  campaign YAML, the GUI, and the pipeline API. Diagnostics identify the tool,
  elapsed time, and configured limit. The base default remains 30 seconds.
- Ligand-selection errors identify available chains and residues; the user guide
  explains that the workbook Chain column selects the ligand copy.
- Since v0.1.1: PoseBusters/PLIP pose-quality analysis, prepared-ligand SDF export
  and backfilling, per-structure pose recovery, unknown-score method selection
  and hover details, loading logs, table copying/Excel export, and pose-loader fixes.
- Documentation states OS support and explains engine extension and downstream
  MD preparation, including the distinction between coordinates and force-field
  parameters.

## Compatibility and scope

Existing result folders and 999.9-based records remain loadable. Report generation
uses the new missing-value semantics; existing saved docking coordinates and
scores are not altered. Completed docking remains resumable even if its reference
RMSD could not be computed. Changing the conversion timeout does not invalidate
ligand preparation caches or completed protocol conditions.

The engine-extension path remains a documented source-level integration, not a
runtime plugin registry. There is no general arbitrary-pose export command or
pH-aware ionization-state enumeration in this release. Neither MD parameterization
nor simulation input decks are generated.

## Validation

- Automated regression suite: 309 passing tests on local Python 3.9. Tests cover
  failed-RMSD export/reload/report/resume, native-reference applicability,
  timeout propagation and diagnostics, ligand-chain errors, and headless font
  scaling/preferences in addition to the existing scientific workflow tests.
- Native macOS GUI checks at 100%, 125%, and 150%, including protocol charts,
  saved protocol pose-recovery tables, saved assay screening, unknown scores,
  progress dialogs, and window resizing. No Tk callback errors were observed.
- Fresh Smina preparation/docking of the public 1E66/HUX example: one condition,
  margin 4 A, all waters removed, exhaustiveness 2, seed 42, three output modes,
  one tautomer/conformer, legacy neutralization, two docking CPUs, no rescoring,
  Open Babel timeout 120 seconds. Score -12.0497942; best RMSD 0.4685384 A.
  A second invocation skipped the completed condition and preserved pose mtime.
  Only public PDB/SDF downloads were reused; preparation and docking were fresh.
- Linux CI is configured for Python 3.9, 3.11, and 3.12. See the release commit's
  Actions checks for their results. The native smoke test verifies workflow
  execution, not predictive accuracy or every external-engine combination.
