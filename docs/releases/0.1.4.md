# DockMate-VS 0.1.4

Release date: 2026-10-28

## Changes

- `screen-prepared` executes intact prepared MOL2 libraries through Smina;
  `import-prepared` reads archived batch output. Both preserve compound IDs,
  topology, failure accounting and provenance, with explicit score mapping.
  These headless routes do not run the native preparation pipeline.
- Native reference selection identifies a non-polymer ligand residue and
  respects the requested chain. Receptor preparation preserves protein
  residues with the same residue name, including the 1X8X TYR regression case.
  Preparation cache identities distinguish corrected runs from older results.
- Shared-frame RMSD calculations use vectorized coordinate comparisons and
  bound correspondence searches. Unsupported Smina/Vina atom types produce
  explicit failures without silently substituting elements.
- Protocol charts load correctly and redraw when switching Top-1/5/10 cutoffs.
- Complete ESR1 S1 and ACHE S2 supplements, checksums, analysis code and
  verification instructions accompany the source release. S1 includes the
  MW-controlled Figure 5/Table 3 analysis and verifier regression tests. S2
  includes all 1,240 compounds, annotation diagnostics, frozen execution
  evidence and the final two-panel Figure 6 regeneration code.

## Validation

Verified locally on macOS with Python 3.11.17:

```sh
python -m pytest dockmate_vs/tests -q -p no:cacheprovider
# 355 passed
```

The separate S1 verifier suite was checked with Python 3.9.15:

```sh
python -m unittest discover -s supplementary/esr1/verification -p test_verify_mw_controlled.py -v
# 7 passed
```

Both complete supplement archives passed their integrity verifiers. The
application test count excludes the seven supplementary verifier tests.
These checks are not a new docking campaign. Linux CI covers Python 3.9,
3.11 and 3.12; its status is reported separately on the release commit.

## Distribution and provenance

`DockMate-VS-0.1.4-source.zip` is the complete tagged repository snapshot for
Zenodo upload. It includes S1/S2 under `supplementary/packages/`, their SHA-256
files, documentation, source, tests and fixtures. A checksum file accompanies
the release asset. External docking executables and environments are not
bundled with the application source; archived evidence retains its documented
scope and third-party terms. See the package READMEs for verification commands.

The working manuscript, standalone submission figures and local output folders
are excluded. Supporting figures within the complete supplements are retained.
Historical case-study software versions, source snapshots and input identities
remain unchanged: publishing this release does not mean those experiments ran
with v0.1.4.
